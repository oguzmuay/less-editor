# A3 run — handoff (bitti)

Crate: `less-rs/crates/less-run`. `CARGO_TARGET_DIR=target/agent-a3`:
`cargo test -p less-run` → **25 test geçiyor** (discovery 8, output 6, process 5, dap 3, variables 3);
`cargo clippy -p less-run --all-targets` temiz; `cargo fmt -p less-run` uygulandı.

## Modüller ve public API

- `paths`: `data_dir()` (`LESS_RS_DATA_DIR`), `run_configs_file()` (`LESS_RS_RUN_CONFIGS_FILE`),
  `breakpoints_file()` (`LESS_RS_BREAKPOINTS_FILE`), `nvim_run_configs_files()` (salt okunur içe aktarma), `mason_bin_dirs()`.
- `model`: `ItemSpec { id, label, detail, cwd, kind }`, `ItemKind::{Spring{tool,file}, Node{pm,script}}`, `Group`,
  `Child`, `GroupKind`, `BuildTool`, `PackageManager`. id'ler LESS-nvim ile aynı (`spring:<dosya>`, `node:<klasör>:<script>`).
- `providers`: `Provider` trait (`discover(root) -> Option<Group>`), `SpringProvider`, `NodeProvider`,
  `default_providers()`, `discover(providers, roots)` (çok kökte `kök › …`).
- `config` (#69): `RunConfig`, `ConfigStore::{open_default, open(path, import), path, get, set}`, `parse_env`, `format_env`.
- `command`: `build(&ItemSpec, &RunConfig, &BuildContext) -> CommandSpec`, `Mode::{Run, Debug}`, `jdwp_options(port, suspend)`,
  `ensure_gradle_init(dir)`.
- `output`: `strip_ansi`, `LineSplitter`, `spring_ready`, `jdwp_port`, `inspector_port`, `app_port`, `is_confirm`,
  `confirm_question`, `PromptTracker` (#77).
- `ports`: `listening_ports`, `listening_pid`, `free_port(_with)`, `can_bind`, `ephemeral_port`.
- `process`: `spawn(spec, rows, cols, on_msg) -> PtyProcess` (setsid, pgid = pid), `ProcMsg::{Output, Exit}`,
  `PtyProcess::{pid, has_exited, write, resize, signal(Sig), stop (HUP→TERM→KILL), force_kill}`, `signal_group`.
- `runner`: `Runner::{new, with(providers, configs, data_dir), set_waker, roots, tree, item, items, ensure_scanned, scan,
  config, set_config(id, cfg, restart), set_profile, log_items, cycle_log(current, step), running, command, start(id, mode),
  stop, toggle, rerun(id, mode?), debug(id, attached), answer(id, yes) -> bool, write, resize, interrupt, force_kill,
  poll() -> Vec<RunEvent>, poll_until, gradle_dir}`. `RunEvent::{Output, Started, Status, Port, Prompt, Attach{target},
  Exited, Notice}`, `ItemState`, `Status`, `AttachTarget::{Java, Node}`.
- `shutdown` (#80): `Shutdown::{begin(&mut Runner) -> Option<Shutdown>` (her çalışana SIGINT)`, rows(&Runner) -> Vec<ShutdownRow>,
  kill(&mut Runner, id), kill_all, finished}`, `ShutdownState::{Stopped, Stopping{..}, Killing}`.
- `dap`: `protocol::{encode, read_message}`; `DapClient::{from_streams, connect, spawn_stdio, request, request_wait,
  respond, initialize, set_breakpoints, configuration_done, threads, stack_trace, scopes, variables, set_variable,
  set_expression, evaluate, step(StepCommand, thread), disconnect}`; `DebugManager::{new, set_waker, set_java_starter,
  attach(runner_id, AttachTarget), attach_addr(runner_id, addr, adapter_type, config), poll() -> Vec<DebugEvent>, state,
  sessions_for, root_session_count, attached_or_attaching, session, sessions, stopped_session, step, detach,
  set_breakpoints(file, bps), replace_breakpoints}`; `DebugEvent::{State, SessionStarted, Stopped, Continued, Output,
  SessionEnded, Failed}`; `JavaDebugStarter` trait (jdtls kancası), `JsDebugServer`, `node_attach_config`,
  `java_attach_config`, `Lang::detect`.
- `variables` (#91 #97): `VariableSource` trait (DapClient uygular), `VariablesModel::{refresh(src, frame?), rows() -> Vec<VarRow>,
  node, parent, toggle, expand, is_expanded, on_stopped, on_continued, on_ended, set_request, apply_set, record_set,
  clear_overrides_under, delete_expr, append_target, append_expr, null_literal}`, `SetRequest`, `ViewStatus`.
- `breakpoints`: `BreakpointStore::{open_default(project), open(path, project), all, for_file, by_file, toggle,
  set_condition, clear_file}` (`breakpoints.json`, `{version: 1, projects: {<kök>: [{file, line, condition?}]}}`).

## Testler (adlarında karar no)

- `tests/discovery.rs`: Spring/Node keşfi, script sırası, çok kök (#16 #26), Spring/Node komut kurulumu (#34 #69),
  run_configs içe aktarma (LESS-nvim dosyası yazılmaz) ve env alanı (#69).
- `tests/output.rs`: ANSI, satır birleştirme, `(Y/n)` tespiti (#77), lsof ayrıştırma, boş port, ready/port (#34).
- `tests/process.rs` (gerçek pty, sahte `npm` script'i): `(Y/n)` → `answer` (#77), ayar argümanları/env (#69),
  rerun + log tab'ları (#101), kapanış: SIGINT `trap`'li süreç kapanır, SIGINT'i yok sayan `kill` ile ölür (#80),
  Node debug çocuk süreç attach hedefi (#34; python3 yoksa atlanır).
- `tests/dap.rs`: çerçeveleme (çoklu mesaj, büyük/küçük harf başlık, eksik başlık, kesik gövde); sahte js-debug
  (TcpListener thread): initialize → attach → initialized → setBreakpoints → configurationDone, `startDebugging` →
  çocuk oturum, stopped + stackTrace, Variables ağacı / setVariable override / yeni durakta `changed`, evaluate, continue,
  detach → iki oturum biter; kapalı porta attach → `Failed` (#34 #91 #97).
- `tests/variables.rs`: Java/JS/Python silme-ekleme ifadeleri (#97), setExpression'a düşme ve override temizliği (#91),
  breakpoint deposu kalıcılığı / proje ayrımı (#92).

Testler yalnız `tempfile` klasörleri kullanır; başlatılan süreçler test sonunda kapanır (testten sonra `pgrep` boş).

## Eksikler / sınırlar

- Gerçek js-debug-adapter ve jdtls/java-debug ile uçtan uca denenmedi (yalnız sahte adaptör). `JsDebugServer::start`
  ve `DebugManager::attach` (Node/Java yolu) test edilmedi; `JavaDebugStarter`'ı less-lang (jdtls) sağlamalı.
- Runner ile DebugManager bağlı değil: UI `RunEvent::Attach` → `DebugManager::attach`, `debug(id, attached)` için
  `attached_or_attaching` değerini vermeli.
- Kapanıştaki "Save all / Discard / Cancel" sorusu UI'ın işi (bu crate yalnız süreçleri yönetir).
- Gerçek Spring (Maven/Gradle `bootRun`) çalıştırması denenmedi; Gradle init script yalnız komut düzeyinde test edildi.
- `VariablesModel::refresh(None)` son tabloyu bırakır (soluk gösterim UI'da).
