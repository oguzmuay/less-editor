## Yapılanlar

- **Notes (#53 #98):** `notes.rs` Cmd+N ile ortada yüzen, çok sekmeli Markdown penceresi. `.less/notes` ve `.gitignore= *`
  `less-workspace::notes` ile; ilk açılışta `Notes`, 300 ms otomatik kayıt, odak kaybı / kapanışta kayıt, Cmd+T yeni not,
  Cmd+Shift/Option+←/→ gezinme, Cmd+N / Cmd+W / Esc kapatma, yeniden adlandırma, Cancel-first dosya silme ve proje başına
  son açık not. Files odaktayken Cmd+N notları açmaz: seçili klasörde `create_new` ile yeni dosya; var olan dosya ezilmez.
  `:Notes [new|rename|delete]`, komut paleti ve kısayol listesi bağlı.
- **Autorestore / düzen / oturum (#30 #32 #66 #81 #99):** `startup.rs` ilk pencerede cwd projesi → cwd oturumu → son kayıt,
  sonraki argümansız örneklerde Welcome; açık klasör/workspace her zaman kazanır. `Instance::register` kullanılır.
  `persistence.rs` her projeye kendi `LayoutStore`, `PinStore` ve session anahtarını verir. Kayıtlı açık paneller ve px
  boyutları ilk gövde ölçüsünden sonra uygulanır; B3'ün varsayılan AI açma isteği kayıtlı düzende AI yoksa yalnız ilk tick'te
  süzülür. Dosya tab'ları, aktif tab, imleç ve pin sırası geri yüklenir. Eski projenin `ProjectView`'i kendi anahtarına yazdığı
  için proje geçişinde eski düzen yenisine taşınmaz. Debug Variables kalıcılığı eklenmedi.
  `LESS_RS_NO_RESTORE=1` / `LESS_RS_AUTORESTORE=0` / `--dashboard` otomatik açmayı kapatır. Geçici veya işaretçisiz projeler
  autorestore/layout/session/pin dosyalarına yazılmaz. Testlerin normal `ProjectView` depoları benzersiz geçici klasördedir.
- **File menüsü (#48 #61 #66):** proje üst çubuğunda eframe `File` menüsü; Open Folder ve en son 15 proje/workspace yeni
  LESS-rs örneğinde açılır. Mevcut proje değişmez. Yeni örnek `current_exe` ile güvenli `std::process::Command` üzerinden
  başlatılır; testler süreç başlatmaz. CLI: `less-rs [FOLDER]`, `--workspace NAME`, `--dashboard`, `--help`, `--version`.
  Göreli proje yolu kalıcı anahtar için mutlak ve mümkünse canonical hale getirilir.
- **Theme / Font (#36 #71):** `:Theme`, `:Font`, Customize ve komut paleti ortak seçiciyi açar. 14 tema ve less-theme'in 12
  fontu; ↑↓ / fare canlı önizleme, Enter / Apply kalıcı seçim, Esc / Cancel açılış değerini geri yükler. Ayarlar
  `config.toml`'a `theme` ve `font` olarak yazılır. Font yalnız LESS-rs'in egui font ailelerine kurulur; kurulu olmayan fontlar
  seçilemez ve varsa Homebrew cask ipucu gösterilir. Ghostty, LESS.app veya başka dış uygulama kontrol edilmez.
- **Sysinfo (#73):** CPU / RAM / disk ve `Leaked IP` proje durum satırının sağında. Örnekleme beş saniyede bir arka planda;
  kaynaklar 120 sütun altında, IP 90 sütun altında gizlenir. Testlerde dış komut çalıştırılmaz.
- **Paketleme:** `scripts/package-macos.sh` release ikilisi, `build/LESS-rs.app`, ZIP ve DMG üretir; `Makefile` check / test /
  clippy / fmt / app / dist / run / install / clean hedefleri. `.gitignore` build çıktısını kapsar, README güncel derleme ve
