## Davranış

- `opened` → `didOpen` (dil varsa), `changed` → artımlı `didChange` (gölge metinle `ContentChange::from_edit`;
  uyuşmazlıkta tam metin), `saved` → `didSave`, `closed` → `didClose`; `tick` → `poll()` ve yanıtlar. `Drop` sunucuları
  300 ms'de kapatır. Bildirimler: sunucu yok (kurulum ipucu), uyarı, çökme, `showMessage`.
- `Unmapped`: `gd` `gr` (bildirim dahil) `gI` `gy` `K` `]d`/`[d` (önce en yüksek önem) `]e`/`[e` `]w`/`[w`.
  Tek konum → `cx.open_file(path, line)` + bir kare sonra sütun; çok konum → liste menüsü (`dosya:satır  metin`).
- Tooltip (#52 #70): CursorHold 200 ms (normal mod / modeless, satırda diagnostik varsa), fare aynı kelimede 350 ms
  (diagnostik + `hover`), `K`. Gerçek tuş kapatır; tooltip artık beklemiyorsa geç gelen hover atılır; CursorHold fare
  tooltip'ini ezmez. Markdown sade çizilir (çitler gizli, başlık vurgulu).
- Sayaç ikonu → o önem derecesinin sonraki problemi, ↑/↓ en yüksek önem; kenar işaretine tık → satır.
- Fare: oluğa tık → breakpoint; Ctrl/Option+tık → tanım; sağ tık → menü (Go to Definition, Find References,
  Rename Symbol, Code Action, Annotate with Git Blame, Add File to AI, seçim varsa Send to AI). Menü ↑/↓/Tab/⏎/Esc
  (`Event::Key` motordan önce), dışarı tık kapatır.
- Rename: kelimeyle dolu giriş kutusu, ⏎ gönderir. Workspace düzenlemesi: açık tab'a tek geri alma adımında (tab
  çizilince), açık olmayan dosyaya diskte. Code action: düzenleme + komut (`executeCommand`), sunucunun `applyEdit`'i.
- Cmd+F8 (`Shortcut`, B2'den önce görür) ve oluk tıklaması → `run.toggle_breakpoint` `"<yol>:<satır 1 tabanlı>"`
  (yerel ayna hemen güncellenir). Gelen `run.breakpoints` `"<yol>:<satır,satır…>"` dosyanın satırlarını değiştirir.
