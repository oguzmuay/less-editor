## Panel sözleşmesi (`src/panels/mod.rs`)

```rust
pub trait Panel {
    fn id(&self) -> &'static str;                       // "git" | "run" | "ai" | "db" (benzersiz, kalıcı)
    fn regions(&self) -> &[Region];                     // çizdiği bölgeler
    fn tick(&mut self, cx: &mut Cx) {}                  // her kare, çizimden önce, görünmese de (kanal yoklama)
    fn ui(&mut self, region: Region, ui: &mut egui::Ui, cx: &mut Cx);
    fn event(&mut self, event: &Event, cx: &mut Cx) -> bool { false }   // true = tüketildi
    fn tab_ui(&mut self, key: &str, ui: &mut egui::Ui, cx: &mut Cx) {}  // kendi açtığı kod tab'ı
    fn tab_event(&mut self, key: &str, event: &Event, cx: &mut Cx) -> bool { false }
    fn tab_closed(&mut self, key: &str, cx: &mut Cx) {}
    fn can_quit(&mut self, cx: &mut Cx) -> bool { true } // false = kapanışı ertele, sonra cx.quit()
}
```

**Bölgeler** (`Region`, `Area` = `less_workbench::layout::Panel`):

| Panel | Bölge | Not |
|---|---|---|
| Git (B1) | `Region::Area(Area::Git)` | sol sütun, Files ile aynı yer (#35); Files host'un |
| Git History (B1) | `Region::Strip(StripPart::Branches)`, `Region::Strip(StripPart::History)` | alt şerit |
| Run (B2) | `Strip(RunTree)`, `Strip(RunLog)`, `Strip(Variables)` | Variables yalnız `layout.vars_visible()` iken gelir |
| AI / Terminal (B3) | `Area(Area::Ai)`, `Area(Area::Terminal)` | sağ sütun, AI üstte (#20) |
| Database (B4) | `Area(Area::Database)` | sağ sütun, AI/terminal'in yerine (#45) |

`ui()` çağrısında `ui.max_rect()` bölgenin tamamıdır (kırpılmış, zemin boyanmamış). Sahibi olmayan bölgede host
"Not available yet" yer tutucusu çizer. Bölgeye tıklamak odağı o `Area`'ya verir. `Region::area()` şerit parçasını
paneline çevirir (Variables → `Area::Run`).

**Olaylar** (`Event`):

| Olay | Kime | Ne zaman |
|---|---|---|
| `Key(KeyEvent)` | odaktaki bölgenin paneli | panel tüketmezse uygulama kısayoluna (`keys::shortcut`) bakılır → Cmd+T/W, Cmd+Shift+←/→ panelin önce görmesi için |
| `Shortcut(KeyEvent)` | sırayla tüm paneller, ilk tüketen kazanır | kimsenin kullanmadığı tuş: F7/F8/F9, Shift+F8, Cmd+F8, Cmd+Enter, Cmd+D, F2… |
| `Ex(&str)` | sırayla | host'un bilmediği ex komutu, `:` yok (`"GitBlame"`, `"R my name"`); kimse almazsa "Not an editor command" |
| `Leader(&str)` | sırayla | Vim `Space` dizisi (`"j"`, `"du"`, `"dr"`, `"D"`, `"ga"`) |
| `Unmapped(&str)` | önce `editor::lang`, sonra sırayla | motorun bilmediği dizi (`"gd"`, `"K"`, `"]d"`) |
| `Layout(Effect)` | herkese | `Opened/Closed/Focused/Hidden/Restored(Area)` — süreç başlatma, odak |
| `Saved(&Path)` | herkese | kod alanında dosya kaydedildi (Git yenileme) |
| `Message { topic, data }` | herkese (gönderen dahil) | paneller arası: `cx.send("run.toggle_breakpoint", "path:line")`; konu `"<id>.<ad>"` |

`KeyEvent` = `less_input::KeyEvent` (`key: Key::{Char, Enter, Esc, Tab, Backspace, Delete, oklar, Home, End,
PageUp, PageDown, F(n)}`, `mods: {shift, ctrl, alt, cmd}`). Yazılan karakterler `Key::Char(c)` (klavye düzeni
uygulanmış), Cmd+C/X/V `<D-c>`/`<D-x>`/`<D-v>` olarak gelir (yapıştırma metni için panel panoyu kendisi okur ya da
`ui()` içinde `ui.input(|i| i.events)`'teki `egui::Event::Paste`'e bakar). Bir egui `TextEdit` odaktayken host
Cmd'siz tuşları hiç dağıtmaz (widget kendisi alır).

**Bağlam** (`Cx`): okunur alanlar `ctx` (egui; arka plan işi bitince `cx.ctx.request_repaint()`), `palette`,
`roots` (proje kökleri), `edit_mode` (Vim / Modeless), `focused`, `active: Option<&EditorTab>` (etkin dosya:
`.path`, `.editor.text()`, `.editor.cursor_line_col()`, `.editor.selection()`), `owner`. İstekler (çağrı bitince
host uygular):

| Metot | İş |
|---|---|
| `cx.open_file(path, Some(line0))` | dosyayı kod alanında aç (varsa o tab), satıra git, koda odaklan |
| `cx.open_text(title, text, Some(Language::…))` | salt okunur, vurgulu metin tab'ı (aynı başlık = içerik yenilenir) |
| `cx.open_tab(key, title)` / `cx.close_tab(key)` | panelin **kendi çizdiği** kod tab'ı (diff, veri tablosu, merge) → `tab_ui(key)`, `tab_event(key)`; aynı key = öne getir + başlık güncelle |
| `cx.layout(LayoutOp::{Open, Close, Toggle, Press, Focus}(Area))`, `ShowVariables`, `HideVariables` | yerleşim (#5, #93) |
| `cx.focus(area)` | aç + odakla (`Area::Code` = koda dön) |
| `cx.info(t)` / `cx.error(t)` | durum satırı + balon + Messages geçmişi |
| `cx.send(topic, data)` | `Event::Message` yayını |
| `cx.quit()` | ertelenen kapanışı yeniden iste |

**Tema:** `cx.palette` (`less_theme::Palette`: `bg`, `surface`, `fg`, `fg_dim`, `comment`, `accent`, `border`,
`bg_highlight`, `error`, `extra.{warn,info,hint,diff_add,…}`, `color(HighlightKind)`, `git_lane(n)`, `mascot(n)`),

## Host davranışı (özet)

- Yerleşim: ilk karede `layout.reset(w,h)`, boyut değişince `clamp_sizes`; kenar sürükleme (sol genişlik, sağ sütun,
  şerit yüksekliği, AI/terminal oranı). Açılışta Files açık (#81'in AI kısmı B3 + C2'de).
- Tuş sırası: kod odakta → uygulama kısayolu → özel tab'ın paneli ya da `lang.event(Key)` + motor →
  `Shortcut` (`lang`, sonra paneller). Files odakta → Files → kısayol → `Shortcut`. Panel odakta → panel →
  kısayol → `Shortcut`. Sahipsiz panel odaktayken Esc koda döner.
- Kısayollar (`keys.rs`, KEYMAP.md): Cmd+0..7, Cmd+Shift+0 (`:UIReset`), Cmd+F / Cmd+Shift+F / Cmd+E / Cmd+K /
  Cmd+Shift+P (Cmd+F artık her modda dosya içi arama çubuğu, dosya araması Cmd+O; bkz. "Kullanıcı düzeltmeleri"), Cmd+Shift+←/→ ve Cmd+Option+←/→ tab, Cmd+T yeni boş tab, Cmd+W
  (kaydedilmemişse ikinci basışta), Cmd+P pin (#30, Cmd+2 ilk pinli tab'a gider), Cmd+Shift+W proje, Cmd+Q = `:qa`.
  Rakam kısayolları fiziksel tuşla (Türkçe düzende Cmd+Shift+0, #42). Option+harf: ASCII yazı üretirse yazı (TR `@`),
  değilse `<M-x>`.
- Ex (`dispatch.rs`): `:Files :Code :AI :Claude :Terminal :Datasource :Run :Git :GitHistory :Messages :UIReset
  :Shortcuts` host'ta; `:w [yol]`, `:wq`/`:x` (yazar, #41 uyarısı), `:wqa`/`:xa`, `:q` → "The code editor stays
  open…" (#41), `:qa[!]` (kaydedilmemiş dosya varsa `!` ister; panellerin `can_quit`'i), `:e [yol]` / `:e!`,
  `:set [no]nu`, `:set [no]rnu` (#54, varsayılan göreli). Tüketilmeyen `Leader` ve `Unmapped` dizileri durum satırında
  "No mapping for …" ile bildirilir; bilinmeyen ex komutu hata verir.
- Durum satırı: mod etiketi, komut satırı / mesaj / bekleyen tuşlar / makro kaydı, yol; sağda `Ln, Col`, satır
  sayısı, Modified / Read-only, keymap, tema.
- Kod görünümü: tree-sitter vurgusu (yalnız görünen satırlar, sürüm başına önbellek), seçim, arama eşleşmeleri,
  blok / çubuk imleç (çoklu imleç), sekme genişletme, tekerlekle kaydırma (`ScrollLines`), tıkla imleç, modeless'ta
  sürükleyerek seçim. Sistem panosu `arboard` (testte bellek panosu).
