# A1 core-input — handoff (durum: **bitti**, 2026-11-11)

`less-core` + `less-input` tamam. **383 test** geçiyor (`cargo test -p less-core -p less-input`),
`cargo clippy -p less-core -p less-input --all-targets -- -D warnings` temiz, rustfmt uygulandı. `document.rs`
dokunulmadı (less-app `Document`, `LoadError`, `MAX_BYTES` kullanmaya devam ediyor). Başka crate'e yazılmadı.

## Akış (arayüz için)

```rust
let mut session = Session::new(Box::new(my_clipboard));     // tüm sekmeler paylaşır
let mut editor = Editor::load(path)?;                         // sekme başına
let mut engine = Engine::new(EditMode::Vim);                  // ya da Modeless
for c in engine.mode_commands() { editor.apply(c, &mut session); }
// her tuşta:
let out = engine.feed(key);
if !out.handled { /* Cmd+1..7, F8 ... uygulama kısayolu */ }
for c in out.commands { if let Some(app) = editor.apply(c, &mut session) { /* :w, :q, Message, Ex, Leader ... */ } }
```

Çizim: `editor.buffer.rope()`, `editor.view` (`top`, `height` — arayüz `height`'i ayarlar), `editor.cursor()`,
`editor.selection().ranges()` (çoklu imleç), `editor.selection_spans()`, `editor.cursor_mode()` (Block/Bar),
`editor.search_matches(&session, first_line, last_line)`, `engine.status()`.

## less-core public API

- `buffer`: `Buffer { path, line_ending: LineEnding{Lf,CrLf}, final_newline, indent: Indent{Spaces(u8),Tabs}, tab_width,
  comment: CommentToken{line, block} }`; `Buffer::from_str`, `load(&Path) -> Result<Buffer, LoadError>` (8 MB + NUL
  koruması, kayıplı UTF-8, CRLF→LF), `save()`, `save_as(&Path)`, `file_contents()`, `rope()`, `text()`, `line(n)`,
  `line_count()`, `len_chars()`, `is_dirty()` (açık insert oturumu da sayılır), `revision()`, `can_undo/can_redo()`;
  `detect_line_ending`, `detect_indent`, `CommentToken::for_path`.
- `history`: `History` (begin/end iç içe, `checkpoint()` = insert'te kaydetme, yazma birleştirme), `Edit`, `RawEdit`.
- `registers`: `trait Clipboard { get_text, set_text }`, `MemoryClipboard`, `Registers { use_system_clipboard }`
  (`"a-z`, `"A-Z` ekleme, `"0`, `"1-9` kayma, `"-`, `"_`, `"+`/`"*`; unnamedplus varsayılan açık), `RegisterContent`,
  `RegisterKind {Char, Line, Block}`.
- `search`: `SearchState`, `vim_to_regex`, `compile(pat, ignore_case, smart_case)`, `find`, `vim_replacement`.
- `selection`: `Range {anchor, head}`, `Selection` (çoklu imleç, `primary`, `normalize`).
- `text`, `motion`, `textobj`: saf rope yardımcıları (kelime/paragraf/eşleşen parantez/f-t, `iw a" i( ip it` ...).
- `command`: `Motion` (h/l/j/k, ok tuşları satır sarmalı #11, w b e ge W B E, Option+Sol/Sağ, 0 ^ $ g_, Cmd+Sol #12,
  gg G, belge başı/sonu, f F t T ; ,, %, { }, H M L, Ctrl-d/u/f/b, / ? n N, mark), `TextObject`, `Operator`
  (Delete, Change, Yank, Indent, Outdent, ToggleCase, Lowercase, Uppercase, Format, Comment), `Target`
  (Motion, TextObject, Lines, Selection, SelectionOrLine, Range), `LineAddr/LineBase/LineRange`, `CursorMode`,
  `VisualKind`, `ScrollAnchor`, `SetValue`, `Command` (tasarımdaki tam liste), `AppCommand`
  (`Write`, `Quit` — uygulama son kod penceresinde reddedebilir #41, `WriteQuit`, `Edit`, `Set`, `Ex(String)`,
  **yeni:** `Leader(String)` (`Space` sonrası tuşlar: `"j"`, `"D"`, `"du"`, `"dr"`, `"ga"`),
  **yeni:** `Unmapped(String)` (motorun bilmediği Normal dizi: `"gd"`, `"K"`, `"]d"` — B5 LSP'ye bağlar), `Message`).
- `editor`: `Editor { buffer, view: View{top,height,scrolloff,preferred_vcol} }`; `new`, `from_text`, `load`, `save`,
  `text`, `selection`, `set_selection` (fare), `cursor`, `cursor_line_col`, `visual`, `cursor_mode`, `overwrite`,
  `mark`, `selection_spans`, `search_matches`, `apply(Command, &mut Session) -> Option<AppCommand>`;
  `Session { registers, search, last_find, clipboard }`, `Session::new(Box<dyn Clipboard>)`; `MotionKind`.
  Uygulanan kurallar: exclusive/inclusive/linewise, `:h exclusive-linewise`, `cw` = `ce`, `dw` satır sonundaki son
  kelimede satırı geçmez, blok imleç satır sonuna geçemez, Esc'te bir sola, kaydırma `scrolloff` ile.

## less-input public API

- `keys`: `Key`, `Mods {shift, ctrl, alt, cmd}` (+ `NONE/SHIFT/CTRL/ALT/CMD`), `KeyEvent {key, mods}`
  (`new`, `plain`, `char`, `is_char`, `plain_char`, `ctrl_char`, `notation`), `parse_keys("d2w<Esc><D-s><M-j>")`,
  `notation(&[KeyEvent])`. Harf tuşlarında büyük/küçük harf karakterde; `<D-x>` = Cmd, `<M-x>`/`<A-x>` = Option.
- `Engine::{Vim(Box<VimEngine>), Modeless(ModelessEngine)}`: `new(EditMode)`, `mode()`, `mode_commands()`,
  `set_mode(EditMode) -> Vec<Command>` (insert'teyse undo grubunu kapatır), `feed(KeyEvent) -> Output`, `status()`.
- `Output { commands, handled }`, `Status { mode_label, pending, recording, cmdline }`, `EditMode {Vim, Modeless}`.
- `vim::VimEngine` (`mode() -> VimMode`, `macro_keys(reg)`, `reset()`, `pub leader: Vec<String>`): Normal / Insert /
  Replace / Visual / V-Line / V-Block / Command; sayaç (operatör sayaçları çarpılır), `"x` register, `.` (sayaç
  ezilebilir), `q`/`@`/`@@`/`N@`, `ZZ`/`ZQ`, `zt zz zb`, Ctrl-e/y, `*` `#` `g*`, `gv`, `gi`, Option+J/K satır taşıma,
  insert: Ctrl-w/u/h/r/t/d, Tab, sayaçlı insert (`3ix`, `2ohi`), görsel blok `I`/`A`/`c` (çoklu imleçle).
- `common::editor_shortcut`: Vim modunda da geçerli LESS tuşları: Cmd+oklar, Option+oklar, Cmd+/, Cmd+S, Cmd+Z /
  Cmd+Shift+Z, Cmd+V, görselde Cmd+C. Diğer Cmd ve F tuşları `handled = false`.
- `modeless::ModelessEngine`: yazma, Shift+ok seçim, Cmd+A/C/V/X/Z/Shift+Z, Cmd+/ yorum, Cmd+Backspace,
  Option+Backspace, Option+Yukarı/Aşağı satır taşı, Cmd+Option+Yukarı/Aşağı imleç ekle, Tab/Shift+Tab (çok satırlı
  seçimde girinti), Esc imleçleri toplar; yazma kelime kelime geri alınır.
- `ex::parse(&str) -> Result<Vec<Command>, String>`: aralıklar (`%`, `N`, `.`, `$`, `'x`, `+N/-N`, `,`/`;`),
  `w[!] [yol]`, `wq`, `x`/`exit`, `wqa`/`xa`, `q[!]`, `qa[!]`, `e[!] [yol]`, `noh`, `s/d/r/fl` (her ayraç, `\(\)`,
  `&`, `\1`, `\r`, `g i I`), `d [x]`, `y [x]`, `j[!]`, `>`/`<`, `u`, `red`, `set` (`x=v`, `nox`, `x!`, `invx`, `x?`),
  `:N`; bilinmeyenler (`:Files`, `:R ad`, `:Theme`, `:wa`) `AppCommand::Ex(metin)`.

## Eksikler / bilinçli sınırlar

- Görsel moddaki operatörler `.` ile tekrarlanmaz; görselde sayaç (`3>`) yok sayılır.
- Jumplist (Ctrl-o / Ctrl-i) ve Ctrl-a / Ctrl-x yok (`Unmapped` olarak uygulamaya gider).
- Makrolar motorda tutulur, register deposunda değil (`"ap` makroyu yapıştırmaz).
- Replace modunda Backspace eski metni geri getirmez; arama ofsetleri (`/foo/e`) yok; komut satırında imleç
  düzenleme, Ctrl-r ve tamamlama yok; `:g`, `:sort`, `:normal`, `:m`, `:t`, `:wa` `Ex` olarak uygulamaya gider.
- `=` (Format) metni değiştirmez; blok `A`'da kısa satırlar boşlukla doldurulmaz; blok sınırı sekmeli satırlarda
  yaklaşık.
- Undo imleci işlemden önceki seçime döner (Vim değişikliğin başına koyar; çoğu durumda aynı yer).
- Yazma birleştirme: boşluk karakteri yeni geri alma adımı başlatır (kelime kelime).
- `[keymap]` TOML yapılandırması (KEYMAP.md "Açık nokta") yok; leader listesi `VimEngine::leader` alanından değişir.
- Fare/Ghostty'de gözle denenmedi (GUI sürülmedi); doğrulama yalnız `cargo test` + `clippy`.
