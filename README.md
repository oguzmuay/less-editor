# nvim-workbench

Ghostty + LazyVim üzerine kurulu, mouse ve klavyeyle kullanılan Neovim ortamı (Java/Spring, TS, SQL, Markdown, Claude Code).

## Kurulum

```bash
git clone <repo> ~/Documents/projects/nvim-workbench
cd ~/Documents/projects/nvim-workbench
./install.sh          # Homebrew paketleri + symlink + eklentiler
```

Mevcut `~/.config/nvim` ve Ghostty config'i varsa `*.backup-<tarih>` olarak kenara alınır.
